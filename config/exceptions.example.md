# Exceptions & comments

> Copy this file to `exceptions.md` (gitignored). Use it to override how the LLM should
> treat specific gaps — things a naive read of your CV would get wrong.

Examples:
- "Job asks for 5y React but I have 3y + strong TypeScript — treat as a soft gap, not hard."
- "I don't list AWS but I've used GCP extensively — count cloud experience as met."
- "Ignore 'German native' requirements; my C1 is sufficient for these roles."
